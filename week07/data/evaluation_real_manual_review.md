| 问题 | 自动失败原因 | 人工复核 | 分类 |

## 结论

- 自动严格口径：44/50（88%）。
- 人工复核后：上述前 5 条语义答案正确，只有 Q39 仍应判失败；即本次样本的语义答案为 49/50。
- 49/50 是对本次报告的人工解释，**不是新的自动评估分数**，也未证明重复运行时结果稳定。

## 对下一周的直接启示

1. Citation Evaluation 不应只比较“引用文档集合是否完全相等”，还要逐条判断陈述是否被引用证据支持。
2. 答案评估前应做 Markdown 清理、全半角及中文/阿拉伯数字归一化；关键词指标仍需人工抽样。
3. Q39 说明 Retrieval Recall=100% 仍不够：相关块进入 Top-3 后，模型仍可能受干扰或漏用证据。
4. Kimi Code 当前模型要求 temperature=1，重复运行可能波动；后续回归应保存原始响应并考虑多次运行统计。
